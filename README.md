# ✨ Féeria Chronicles : Black Sheep Tournament 4

Bienvenue dans **Black Sheep Tournament 4**, une reproduction historique d'un *vrai* jeu auquel s'adonnaient régulièrement les habitants de Bubouland,
jusqu'à son interdiction en 758 par son altessissime altesse Hubert III lors de la 6ème (et dernière) édition.
Êtes vous prêt à vous plonger dans la 4ème édition de ce tournoi ?

---

## 🎮 Concept du jeu
- ### Mode *BS:GO* :
  - **2 équipes de 2 joueurs**
  - **1 mouton** 
  - **L'objectif** : L'équipe portant le mouton doit l'*immoler* par les flammes sous l'un des obelisks présent sur la carte. L'autre équipe doit l'éteindre à temps.   
- ### Mode *Hill* :
  - **de 2 à 4 équipes**
  - **Un minuteur de 10 minutes**
  - **L'objectif** : Le joueur avec le plus haut score remporte la partie !

---

## ⚔️ Mécaniques principales
- **5 personnages jouables** : Tank, healer, DPS, ...
- **Compétences uniques** : potions de soin, buffs temporaires, obstacles destructibles
- **Victoire** :
  - Brûler entièrement le mouton / l'éteindre
  - Eliminer toute l’équipe ennemie

---

## 🖥️ Technologies utilisées

- **Langage** : C
- **Librairie graphique** : CSFML
- **Moteur** : Raycasting (2.5 D)
